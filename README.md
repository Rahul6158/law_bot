# LexAI - Indian Penal Code Legal Assistant

LexAI is a sophisticated Retrieval-Augmented Generation (RAG) chatbot designed to act as a legal counselor focusing on the Indian Penal Code (IPC). Powered by local embeddings and the Groq API (Llama 3.3), it provides rapid, structured, and legally context-aware responses to user queries.

---

## Architecture & Process Flow

The system runs heavily on a robust NLP ingestion pipeline combined with the lightning-fast Groq LLM:

1. **Document Ingestion** (`injest.py`):
   - The raw IPC law documentation (`ipc_law.pdf`) is loaded using LangChain's document loader.
   - It is chunked into consumable textual segments and processed through local `HuggingFaceEmbeddings` (specifically relying on the `all-MiniLM-L6-v2` dense representation model).
   - The resulting vector embeddings are stored efficiently in a highly indexed **FAISS Vector Database** (`ipc_vector_db/`).

2. **Semantic Retrieval**:
   - Whenever an end-user sends a legal query in the chat UI, the backend (`app.py`) instantly searches the FAISS database for the highest-matching text chunks related to their query. 
   - These relevant law snippets are pulled out as verified local context to strictly ground the AI's answer.

3. **Inference with Llama 3.3 via Groq**:
   - The user's query, merged with the context sourced from our local database and recent session history, is injected into a structured system prompt.
   - The payload is dispatched to the **Groq AI** endpoint using the `llama-3.3-70b-versatile` model.
   - Groq synthesizes the best answer enforcing strict structural formatting (including applicable sections and consequences), which is sent smoothly back to the visually stunning responsive web front-end!

## Setup & Run Instructions

Follow these steps to deploy LexAI locally:

### 1. Requirements

Make sure you have Python 3.9+ installed. First, install the necessary dependencies via the terminal:

```powershell
pip install -r requirements.txt
```

### 2. Environment Variables

Create a file named `.env` in the root of the repository and securely add your Groq API key:

```env
GROQ_API_KEY=your_groq_api_key_here
```

### 3. Generate Vector Database

Before running the web server, you MUST ingest the IPC PDF to construct your FAISS vector database. Run the `injest.py` script:

```powershell
python injest.py
```
*(Note: Generating vectors via local CPU HuggingFace pipeline may take a few minutes.)*

### 4. Start the Application

Once your database is created inside `ipc_vector_db/`, initialize your Flask backend server:

```powershell
python app.py
```
Or alternatively use the flask module runner:
```powershell
python -m flask run
```

Finally, simply open your preferred browser and navigate to `http://127.0.0.1:5000` to start seeking consultation with LexAI!
